# Trackfy

Tracking, Attribution & Revenue Intelligence.

Trackfy is a multi-tenant SaaS for collecting marketing events, connecting them to conversions, attributing revenue, and making performance data understandable and actionable.

## Status

Early foundation. Product and engineering specifications are being defined before production implementation.

## Principles

- Specifications before implementation.
- Contracts before integrations.
- Tests define observable behavior.
- Deterministic verification over plausible output.
- Multi-tenancy is a first-class constraint.
- Events are immutable facts; derived analytics are recomputable.
- Revenue metrics distinguish gross, approved, pending, refunds, fees, costs, and profit.
- Observability is part of the product.
- Prefer the simplest architecture that satisfies the requirements.

## Domains

Tracking, event collection, sessions, visitors, clicks, campaigns, conversions, orders, attribution, revenue intelligence, integrations, webhooks, event debugging, organizations, workspaces, RBAC, API and developer tooling.
